Instead of calling them "outdated components," make it clear these are vulnerabilities **without known active threat activity**.

### Recommended Title

**Multiple Software Components Containing Known Security Vulnerabilities**

or

**Multiple Third-Party Software Components with Known Security Vulnerabilities**

or (my preferred title)

**Multiple Installed Software Components Running Vulnerable Versions**

---

### Description

During the assessment, multiple installed software components were identified as running versions affected by publicly disclosed security vulnerabilities. Although these vulnerabilities are **not currently associated with known threat activity** based on available threat intelligence, they remain exploitable under specific conditions and could be leveraged by attackers to compromise affected systems.

The identified vulnerabilities affect multiple third-party software components, including:

* Chromium-based browsers
* OpenSSL
* Microsoft .NET Runtime
* Axios
* Microsoft Visual Studio components
* Forescout

Depending on the affected component, successful exploitation may result in remote code execution, information disclosure, security feature bypass, denial of service, authentication bypass, or privilege escalation. Timely updates are recommended to reduce the attack surface and maintain a secure software environment.
