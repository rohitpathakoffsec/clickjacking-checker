Validation of the workstations was performed using the VM1 Microsoft Defender vulnerability reports as the baseline, as the workstations are production systems and no pre-production instances were available. As part of the validation approach, vulnerabilities with Has Exploit = Yes were prioritized and validated first, followed by vulnerabilities with Known Threats = Yes. The remaining findings were then validated by collecting the actual operating system and software versions from the hosts using PowerShell scripts and comparing them against the respective vendor security advisories, affected versions, and fixed versions. Available system evidence was reviewed to determine the applicability of the reported vulnerabilities. No active exploitation or intrusive testing was performed on the production workstations.
